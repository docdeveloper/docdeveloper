I’m a technical writer turned software developer. 

## Bio
I’ve always had a knack for technical things so at some point I got interested in learning how to code. 

My first choice was Python. The knowledge of Python opened up new career possibilities for me and sped up the process of picking up other languages. 

After 8 years of writing technical documentation I became a documentation tools developer. I’m currently working at Guidewire Software where I take care of the tools and infrastructure that enables writers to deliver high quality docs and clients to get information they need when they need it.
